# Studi_Kasus_4_Celsines Rante Tasak

Penjelasan Kode
produk → buat nyimpan data produk, seperti nama, harga, dan stok.

while True → supaya menu terus muncul selama program masih dijalankan.

print() → buat menampilkan tulisan atau menu.

input() → buat menerima pilihan atau data dari pengguna.

if, elif, else → buat menentukan program harus melakukan apa sesuai pilihan pengguna.

Pilihan 1 → buat melihat data produk.

Pilihan 2 → buat menambahkan kategori produk.

Pilihan 3 → buat mengubah harga produk.

Pilihan 4 → buat menghapus kategori produk.

Pilihan 5 → buat keluar dari program.

break → untuk menghentikan perulangan atau keluar dari menu.

del → buat menghapus data kategori.

print(produk) → buat melihat data produk setelah diubah.
